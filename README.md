## The entry

`main.py` (deterministic, stdlib-only) writes one funny single-line one-star
review from a house cat about its human to `/output/entry.txt`:

> One star. He bought a heated cat bed, then sat in it himself. I now sleep on his laptop. He works standing up.

110 characters, one line.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
